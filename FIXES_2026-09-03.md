# Fixes (2026-09-03)

1. **Update button / Loading issue**
   - Plotly graph DOM is no longer overwritten by a loading message after the graph has been initialized.
   - Existing graphs are updated with `Plotly.react()` while a non-destructive loading overlay is shown.
   - Update buttons are temporarily disabled while an update is running.

2. **News Analysis x-axis**
   - News time indices are explicitly converted to JavaScript strings.
   - The Plotly x-axis is explicitly set to `type: 'category'` with chronologically ordered string categories.
   - This prevents numeric-looking labels such as `200601` from being interpreted as a continuous numeric axis.

3. **Factor Analysis treemap**
   - Non-finite source values (`Infinity`, `-Infinity`, `NaN`) are converted to JSON `null` during the build step.
   - The treemap JSON is now standards-compliant and can be parsed by browsers.
